Lista de especialidades no painel vira colunas uniformes em vez de chips soltos

As opcoes de especialidade eram chips (pilulas) com display:flex/flex-wrap,
de larguras bem diferentes dependendo do texto, ficando visualmente
baguncado. Agora e uma lista de linhas uniformes (checkbox + texto,
separador sutil), organizada em 2 colunas via CSS columns — preenche a
primeira coluna de cima pra baixo e continua na segunda, em vez de ficar
muito comprida numa coluna so.

Backend + painel da galeria de Fotos e videos tambem entram nesse commit
(tabela galeria_fotos, rotas /api/psicologos/me/galeria, UI de upload no
painel) — falta so a parte de exibicao no perfil publico.
